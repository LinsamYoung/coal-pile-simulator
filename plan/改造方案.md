# 圆形煤场屋顶雷达扫描仿真改造方案

## 目标

在现有圆形煤场页面支持屋顶高位布置多台雷达，生成每台雷达在云台完成一次扫描后的累计煤面点云，用于 BUFFER-X 多视角点云拼接验证。场景保持静态快照，直接计算累计结果，不要求展示云台旋转过程。

## 扫描模型与参数约定

雷达正常安装时，其旋转形成的主要扫描面为水平面，原竖直线束具有上下角度范围。将雷达侧装约 90° 后，主要扫描面变为竖直面，原竖直视场随安装姿态转换，影响场地左右方向的线束分布。云台带动雷达绕铅垂方向改变朝向，累计后从俯视角度呈扇形或周向覆盖。

每台雷达配置以下参数，角度均使用度、距离使用米。

| 参数 | 说明 |
| --- | --- |
| 雷达位置 | 料场坐标系下 X、Y 和离地高度 Z，可放置在圆场投影范围内 |
| 安装姿态 | 默认侧装 90°，定义雷达旋转轴的方向；初始朝向可调整 |
| 原竖直视场 | 侧装前线束相对雷达水平扫描面的下限和上限，分别可调 |
| 云台累计范围 | 起始方向和转过的角度，支持跨越 0° 与完整 360° |
| 线束数量 | 未指定真实型号时在原竖直视场内均匀布置，界面标明该假设 |
| 雷达旋转角间隔 | 控制竖直扫描线上相邻采样方向的间隔 |
| 云台角度间隔 | 控制用于计算累计结果的离散方向间隔 |
| 有效量程 | 每条射线的最短和最长测量距离 |

原竖直视场与云台累计范围分别配置。实际最终覆盖由两者及安装姿态共同决定，不能简单将二者相加作为固定扇区宽度。未指定具体型号时，上述参数生成理想化扫描分布；真实设备应以线束角度表、安装外参和云台参数校准。

## 交互与布站

- 点击新增雷达后，在俯视图内通过鼠标选定屋顶投影位置，预览标记跟随鼠标，左键确认，Esc 取消。
- 在雷达属性窗中编辑高度、姿态、原竖直视场、云台累计范围、采样间隔和量程，也可删除雷达。支持对已有雷达的参数继续编辑。
- 初始试验可使用四台雷达，投影点距圆心约 25–35 m、离地约 40–50 m、方位约间隔 90°。这些是便于比较的仿真初值，最终应以实际扫描覆盖、重叠结果与场地结构确定。
- 半透明遮罩展示累计扫描方向的俯视范围，裁切在料场内。标注它表示方向范围，煤堆遮挡后的实际可见区域以扫描计算结果为准。
- 保留墙顶布站能力，便于对比现有墙顶与屋顶站位。

## 累计点云生成

1. 用户触发扫描时冻结煤堆高度场和所有雷达配置，各雷达基于同一份快照计算。
2. 将原雷达线束方向按侧装姿态变换，再按离散云台角度变换到场地坐标系，批量得到整次扫描的候选射线。云台角度用于数学采样，无需动画或实时模拟。
3. 按有效量程和场景几何求每条射线的首个交点，仅将首次命中煤面的结果输出为点。地面、中央空区与完整挡墙参与遮挡；显示用挡墙剖视状态不改变扫描计算。
4. 支持竖直向下的射线，以及雷达位于圆形场地内部时任意有效方向的圆墙交点。自动处理跨 0°、360°、边界和无命中情况。
5. 明确相邻云台姿态、不同线束或对向扫描形成的重复点处理方式。默认保留采样结果，可配置去重容差，去重规则对所有雷达一致。
6. 采用按高度场网格遍历等加速方式；大点数计算放入 Worker 或分批执行，显示进度并允许取消。每次扫描完成后用于预览、统计和导出的点云应对应同一个快照。

每台雷达一次累计扫描得到一组点。建议记录雷达标识、采样配置和快照信息供页面显示与复现，ZIP 中维持现有仅包含 PLY 的约定。

## 点云与坐标

- 独立完整煤面 PLY 使用场地统一坐标，圆心为原点，Z 轴向上。
- 雷达 ZIP 包含 `yard_coordinates/` 和 `radar_local/` 两个目录，每台雷达在两个目录各有一个同名 PLY，分别保存统一坐标和雷达本地坐标；空扫描也保留成对的零点 PLY。
- 每台雷达只扫描一次，两种坐标文件由同一组命中点转换得到，点数与顺序一致。
- 现有本地坐标定义为雷达安装位置为原点、+X 指向场心、+Y 面向场心时朝左、+Z 向上。该坐标系作为固定站位坐标系，与累计扫描过程中变化的瞬时雷达坐标区分。
- PLY 注释写明坐标约定、雷达编号与站位。增加可调初始朝向后，本地坐标系的朝向应明确定义并保留转换所需信息；不得因云台扫描角而让同一文件内的点使用不同坐标系。

## 覆盖和拼接验证

- 提供单台可见煤面预览及雷达两两共同可见区域预览，支持选择点距离阈值，并同时显示 A→B、B→A 的最近邻匹配比例、有效点数和参数。该指标属于点云距离统计，须注明受采样密度和阈值影响。
- 可增加基于同一煤面网格的可见面积统计，与点到点统计分别显示；明确网格尺寸和分母。初期 30%–50% 可作为布站实验的比较区间，不作为 BUFFER-X 的成功保证或工程验收门槛。
- 对比不同煤堆形态、屋顶和墙顶站位。观察相邻雷达的重叠关系是否形成连通链，并将已知站位变换作为计算配准旋转误差和平移误差的真值。
- 同一批次同时导出完整煤面和雷达点云，或在页面保留可追溯的快照标识，避免将不同煤堆状态误作同一批次比较。

## 现有代码改造方向

- `src/simulation/RadarSimulation.ts` 扩展雷达配置、姿态与累计射线生成，修正圆内起点求交及竖直向下的射线处理，继续复用高度场首击和快照机制。
- `src/scene/RadarVisuals.ts` 与 `src/scene/SceneController.ts` 支持屋顶投影选点、三维雷达标记、周向遮罩和扫描可见性显示。
- `src/circular-yard.ts` 更新新增雷达和属性交互，提供扫描进度、参数和覆盖统计。
- `src/io/RadarExporter.ts` 沿用同一组点生成双坐标 PLY 的流程，扩展坐标注释与站位信息，保持现有 ZIP 目录和完整煤面入口。

## 验收

1. 不同高度和场内位置均可放置、编辑、删除雷达；墙顶布站、场景堆取料和原有页面入口正常。
2. 已知简单几何下，验证侧装姿态、线束角、云台角的方向，以及跨 0°、360° 和竖直向下的射线；非零视场下用明确射线集合验证最终覆盖边界。
3. 使用近高堆和远低堆验证首击遮挡，切换显示剖视后结果不变；验证圆内雷达对墙体、地面、中央空区和量程的处理。
4. 同一快照的完整煤面及多雷达扫描结果一致；对每台雷达验证双坐标 PLY 点数、顺序、单位和坐标转换，ZIP 仅包含成对 PLY，空扫描文件可读。
5. 测试已知变换的点云与双向重叠统计，并对多个煤堆形态比较屋顶及墙顶站位。明确距离阈值、采样间距和评估口径。
6. 浏览器中验证放置、拖动、属性编辑、范围遮罩、扫描取消、进度和导出；运行项目测试与生产构建，核对较大扫描任务的响应性。

## 待设备资料确认

具体雷达型号、线数、各线束角度、旋转采样率、有效量程、侧装偏置及云台转角范围。若后续需要逼近真实采集，还需确认扫描周期内煤堆或设备是否移动，以及噪声、漏点和云台定位误差的模型。
